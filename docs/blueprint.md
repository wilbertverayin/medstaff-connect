# **App Name**: MedConnect PH

## Core Features:

- User Authentication: Secure authentication via email and Google for doctors and HR personnel.
- Doctor Profiles: Detailed profile creation for doctors, showcasing their credentials, specializations, and availability.
- Job Board: Job posting module for hospitals/clinics with detailed job specifications and filtering options.
- Referral Bulletin: Referral board for doctors to share urgent cases, equipment sales, CME opportunities, and collaboration requests.
- Secure Chat: Direct messaging system exclusively for verified users.
- Smart Matching: Smart matching tool that suggests doctors to HR based on job post criteria. This feature uses AI to find ideal candidate matches for each job post.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6) to convey trust and professionalism in the medical field.
- Background color: Off-white (#F9F9F9), providing a clean, modern, and professional backdrop.
- Accent color: Soft green (#90EE90) to highlight important actions and elements while keeping a subtle and clean style.
- Body and headline font: 'Inter', a sans-serif font, for a clean and modern user experience. Inter is appropriate for both headlines and body text.
- Simple, clean icons for easy navigation. Use icons to visually represent job types, specialties, and referral categories.
- Clean and structured layout to ensure the information is easily digestible. Employ card-based design for job and referral listings.
- Subtle transitions and animations to provide a smooth user experience when navigating and loading data.
